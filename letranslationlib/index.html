Single Motor Functions

Add await before hardware calls so each command finishes before the next one starts.

Connect to the motor

sm.connect(card_color=color, card_serial='1234')

Spin the motor this many rotations

await sm.spin(rotations)

Stop the motor

await sm.stop()

Set the motor speed (1–100)

sm.set_speed(speed)

Run the motor continuously

await sm.run()

Double Motor Functions

Add await before hardware calls so each command finishes before the next one starts.

Connect to the motors

dm.connect(card_color=color, card_serial='1234')

Move this many steps (1 step = 180°)

await dm.move_steps(1)

Run the motors continuously

await dm.run()

Run for this many milliseconds

await dm.run_time(milliseconds)

Run the left motor

await dm.run_left()

Run the right motor

await dm.run_right()

Turn left by this many degrees

await dm.turn_left(degrees)

Turn right by this many degrees

await dm.turn_right(degrees)

Set the speed of both motors (1–100)

dm.set_speed(speed)

Stop the motors

await dm.stop()

Controller Functions

Add await before hardware calls so each command finishes before the next one starts.

Connect to the controller

c.connect()

Drive the double motor with the controller sticks for 10 seconds

await c.drive(dm)

Return True if left stick is pushed up

c.left_up()

Return True if left stick is pushed down

c.left_down()

Return True if left stick is released

c.left_released()

Return True if right stick is pushed up

c.right_up()

Return True if right stick is pushed down

c.right_down()

Return True if right stick is released

c.right_released()

Color Sensor Functions

Connect to the color sensor

cs.connect(card_color=color, card_serial='1234')

Return the detected color as a string

cs.detect_color()

General Python Tips!

Wait between commands — pause for a number of seconds:

await wait(2)

if statements — make decisions:
Example: Green means go!

if cs.detect_color() == 'Green':
    print('The color is green!')
    await dm.run()

for loops — repeat a set number of times:
Example: Move 5 steps!

for i in range(5):
    await dm.move_steps(1)
    await wait(0.5)

while loops — repeat until a condition is met:
Example: Drive until we see red!

while cs.detect_color() != 'Red':
    await dm.run()
await dm.stop()
