Single Motor Functions

connect to the motor

sm.connect(card_color=color, card_serial='1234')

spin the motor this many degrees

sm.spin(degrees)

stop the motor

sm.stop()

set the motor speed

sm.set_speed(speed)

run the motor

sm.run()

Double Motor Functions

connect to the motors 

dm.connect(card_color=color, card_serial='1234')

move this many steps!

dm.move_steps(1)

run the motors 

dm.run()

run the motors for this many milliseconds 

dm.run_time(time)

run the left motor

dm.run_left()

run the right motor

dm.run_right()

turn left by this many degrees

dm.turn_left(degrees)

turn right by this many degrees

dm.turn_right(degrees)

set the motor speed 

dm.set_speed(speed)

set the left motor speed 

dm.set_speed_left(speed)

set the right motor speed

dm.set_speed_right(speed)

stop the motors

dm.stop()

Controller Functions

connect to the controller

c.connect()

control the double motor for 10 seconds using the controller sticks

c.drive(dm)

return True if left stick is up

c.left_up()

return True if left stick is down

c.left_down()

return True if left stick is released

c.left_released()

return True if right stick is up

c.right_up()

return True if right stick is down

c.right_down()

return True if right stick is released

c.right_released()

Color Sensor Function

connect to the color sensor

cs.connect(card color, serial number)

return the detected color

cs.detect_color()

General Python tips!

if statements - use these to make decisions in your code
Example: Green means go!


            if cs.detect_color() == 'green':
                print('The color is green!')
                dm.run()

for loops - use these to repeat code a certain number of times
Example: Spin 5 times!

            for i in range(5):
                sm.spin()

while loops - use these to repeat code until a condition is met
Example: Spin until we see red!

            while cs.detect_color() != 'red':
                sm.spin()
