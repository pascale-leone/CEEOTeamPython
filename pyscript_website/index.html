wait(seconds)
Pause for this many seconds. This code can run really fast, so use wait() in your loops to execute over a certain amount of time!
if/elif/else
If statements check for conditionals. Check if something is true, and if it is, do this! Add else or elif to add multiple execution pathways
if cs.detect_color() == 'green': dm.run() elif cs.detect_color() == 'red': dm.stop()
conditionals
equals - ==
not equals !=
greater than >
greater than or equal to >=
less than <
less than or equal to <=
Combine conditionals using and/or!
if speed >= 50 and color == 'yellow': speed = 20 print('Slow down!')
for loops
Execute a block of code a certain number of times. Use wait() to pause between instances!
for i in range(5): sm.spin(1) wait(0.5)
while loops
Execute a block of code while a condition is met
while cs.detect_color() != 'red': dm.run() wait(0.1)
print statements
Print statements can be helpful for debugging, and making sure your program is executing as expected. To print a message, use print('') or print(""). To print a stored variable, use print(variable_name).
color = cs.detect_color() print('color detected!') print(color)
